# 🩺 Doctor Appointment Booking System

A full-stack web application that allows patients to book appointments with doctors online.

This was my **second full-stack project**, built using **React**, **Laravel**, and **MySQL**. The system includes user registration, appointment booking, doctor management, and an admin dashboard. It helped me improve my understanding of CRUD operations, authentication, and role-based features in a real-world context.

---

## 🚀 Features

- 🧑‍⚕️ Patient and doctor registration/login
- 📅 Book, cancel, or manage appointments
- ⏰ View doctor availability and schedule
- 🧑‍💼 Admin dashboard to manage users, doctors & appointments
- 🔐 Role-based access for admin, doctors, and patients

---

## 🛠️ Tech Stack

- **Frontend:** React  
- **Backend:** Laravel (PHP)  
- **Database:** MySQL  
- **API Communication:** RESTful APIs

---

## 📚 What I Learned

- Implementing multi-role authentication (admin, doctor, patient)
- Working with calendar/availability systems
- Building and consuming APIs between Laravel and React
- Managing application state and user sessions
- Better understanding of UI/UX and data validation
